# 💰 Desafio Dinâmico: Poupança Diária

Repositório dedicado ao desenvolvimento de soluções em lógica de programação e automação financeira utilizando Python. Este projeto foca em simulações e controles práticos para metas de poupança.

---

## 📂 Estrutura do Repositório

O projeto está organizado da seguinte forma:

| Arquivo / Pasta | Descrição |
| :--- | :--- |
| **`Desafio Poupança Diária`** | Pasta contendo os arquivos, códigos e simulações principais do desafio de planejamento financeiro. |
| **[`Untitled1.ipynb`](./Untitled1.ipynb)** | Notebook desenvolvido no Google Colab para testes rápidos, execução de lógica e validação dos scripts em Python. |

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Python:** Linguagem principal para o desenvolvimento da lógica de cálculo e simulação.
* **Google Colab:** Ambiente interativo em nuvem utilizado para rodar e testar os códigos.
* **Lógica de Programação:** Estruturas de repetição, condicionais e manipulação de dados numéricos.

---

## 📊 Sobre o Desafio

* **Objetivo:** Criar um algoritmo ou estrutura em Python capaz de simular, calcular e acompanhar o progresso de uma meta de poupança diária de forma automatizada.
* **Destaques:** Foco em resolver problemas práticos do cotidiano usando programação, código limpo e escalável.
